# Student Portal - End Sem Project

A modern, responsive React web application featuring user authentication and a student profile dashboard.

## 🎓 Overview

This project was built for the **End Sem Project / Lab Exam**. It provides:
- **Authentication System**: Controlled form validation with error handling and secure conditional rendering.
- **Student Dashboard**: Clean, responsive profile dashboard displaying personal and academic information.
- **Modern UI/UX**: Styled with an intuitive layout, card grid, and responsive design.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Nikhil80056/end-sem-project.git
cd end-sem-project
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
